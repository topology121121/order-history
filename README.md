# My orders: mobile layout options

Static prototype of the "My orders" screen for the store's mobile web app. All data is synthetic.

- `main`: shared data (`data/orders.js`), base styles and the product request (`docs/REQUEST.md`)
- `layout/scroll-table`: horizontally scrollable table
- `layout/stacked-cards`: stacked cards

Open `index.html` in a browser on either layout branch. No build step needed.
